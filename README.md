# Sekolah Karir — Recruitment Landing Page
Mini assignment Web Developer: responsive recruitment landing page dengan headline, role cards, CTA, dan mobile layout.

## Teknologi
- HTML5 untuk struktur halaman dan semantic markup.
- CSS3 untuk visual design, layout, dan responsive breakpoints.
- JavaScript untuk filter kategori lowongan dan tahun footer.
- Bootstrap 5.3.3 untuk navbar responsive, grid system, utility classes, dan collapse component.

## Menjalankan proyek
1. Download atau clone repository.
2. Buka folder proyek.
3. Jalankan `index.html` di browser. Untuk pengalaman development, gunakan extension Live Server di VS Code.
4. Koneksi internet diperlukan untuk memuat Bootstrap CDN dan Google Fonts.

## Fitur
- Responsive navigation dengan menu mobile.
- Hero section dan CTA menuju daftar posisi.
- Informasi budaya kerja.
- Empat contoh kartu lowongan.
- Filter posisi berdasarkan Technology, Creative, dan Marketing.
- Tombol Apply membuka draft email melalui `mailto:`.

## Keputusan desain
- Menggunakan palet hijau lembut, putih, dan hijau gelap untuk memberi kesan segar dan profesional.
- Menggunakan layout card agar informasi posisi mudah dipindai.
- Menggunakan Bootstrap grid dan breakpoint CSS agar konten menyesuaikan layar.
- Data lowongan merupakan mock data untuk kebutuhan demonstrasi, bukan informasi rekrutmen aktual.
